# python-learning-projects

Sammlung von alten kleinen Python Projekten aus meiner Anfangszeit (die meisten davon ca. 2023) die ich zum Lernen gemacht hab. Waren einzeln alle zu klein für ein eigenes Repo, deshalb sind sie hier alle zusammen gebündelt.

Jedes Projekt hat sein eigenes kleines README mit dabei.

- **a-star** – A* Pathfinding-Algorithmus in der Console
- **deat** – neuronales Netz komplett selbst geschrieben
- **gameOfLife** – Conways Game of Life in der Konsole
- **screenshot-taker** – kleines Tool, das automatisch Screenshots macht
- **untis** – Tools um WebUntis-Daten auszulesen (einer der neueren Projekte, trotzdem noch zu klein für ein eigenes Repo)
